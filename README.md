# CFA Level I Mock Exam Portal 🎓✨

A personalized, cute, and ultra-lightweight web-based exam portal built for CFA Level I candidates. 

## Features
- **2 Full Session Mocks (180 Questions Total)**:
  - Session 1: Ethical & Professional Standards, Quantitative Methods, Economics, Financial Statement Analysis
  - Session 2: Corporate Issuers, Equity, Fixed Income, Derivatives, Alternative Investments, Portfolio Management
- **Cute Pastel Aesthetics & Dark/Light Mode**: Smooth glassmorphism cards and micro-animations.
- **Real Exam Environment**: Live countdown timer, option choices (A, B, C), question flagging (`🚩`), and interactive **1..90 Question Palette Drawer**.
- **Automated Grading & Detailed Corrections**: Score percentage, pass evaluation (70%), filterable questions view (`[All]`, `[Incorrect ❌]`, `[Correct ✅]`, `[Unanswered ⚪]`), and step-by-step solution explanations.
- **LocalStorage Persistence**: Stores past test attempts and analytics.
- **Vercel Ready**: Vite + React + Vanilla CSS SPA architecture.

## Getting Started Locally

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build production bundle
npm run build
```

## Vercel Deployment
Deploy directly to Vercel with 1 click by importing this repository and selecting **Vite** as the framework preset.
